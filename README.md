# Luch

Luch is a first-person 3D puzzle, sruvival game developed in Unity as part of a matura final project. The player must escape a prison facility by solving puzzles, collecting items, avoiding dangerous light zones, and staying out of sight of a robotic guard.

This repository was used mainly for version control and backup during development, so the commit history is mostly on the `main` branch and many commit messages are in Slovene. It is shared here as an example of my Unity and C# work.

## Features

- First-person movement
- Two-slot inventory and item interaction system
- Puzzle-based progression with switches and keypad locks
- Enemy AI with patrol and chase behavior
- Light-based detection
- Main menu and audio settings

## Tools

- Unity 2022 LTS
- C#
- Visual Studio
- Git and GitHub

## Note
As a solo project, the main focus was on building and programming gameplay systems rather than creating all visual assets from scratch, so the project also uses some AI-generated meshes and other third-party assets.
